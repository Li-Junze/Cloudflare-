# ============================================================
#  Cloudflare Pages Deployer - 依赖清单
# ============================================================
#  本项目是 PowerShell + WPF 实现，无需 Python 包。
#  以下组件由 init.bat 自动检查/安装，使用者无需提前准备。
#
# ---- 系统运行时（init.bat 自动安装）----
#   powershell >= 5.1      Windows 10/11 自带，无需安装
#   node       >= 14       缺则经 winget 自动安装；无 winget 时引导手动安装
#   npm        >= 6        Node.js 附带
#   wrangler   >= 3.0      Cloudflare 官方 CLI，缺则 npm 自动安装
#
# ---- 需要使用者自备 ----
#   一个 Cloudflare 账号（免费注册）
#     https://dash.cloudflare.com/sign-up
#   说明：init.bat 会询问并引导注册，随后打开浏览器完成授权。
#         授权令牌仅保存在本机，工具不保存密码。
#
# ---- 网络要求 ----
#   可访问 cloudflare.com 与 registry.npmjs.org
#   若网络受限，init.bat 会提示改用镜像源：
#     npm config set registry https://registry.npmmirror.com
#
# ---- 可选（仅开发/测试需要）----
#   python >= 3.8   用于 tools/ 下的辅助脚本
#   pillow          图片处理，配合界面截图工具
#
# ---- npm 依赖（由 init.bat 执行 npm install -g wrangler 安装）----
wrangler>=3.0.0
